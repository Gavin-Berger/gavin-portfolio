# Your photos

Drop JPGs in this folder with these exact names. Each one appears on its stop's card, in
the plain-text version of the site, and on an easel in the 3D scene. Any photo you leave
out is simply skipped: no placeholders and nothing broken.

| File             | Where it shows up                                  |
| ---------------- | -------------------------------------------------- |
| `portrait.jpg`   | Trailhead and summit (round headshot), story page  |
| `college.jpg`    | University of North Georgia stop                   |
| `events.jpg`     | Events by Design stop                              |
| `music.jpg`      | Music stop                                         |
| `graduation.jpg` | Graduation stop                                    |

Tips: about 1600px on the long side, under 500 KB each. Landscape works best for the
stop photos, and a square or portrait crop works best for `portrait.jpg`.

To add a photo to another stop, give that stop a `photo` in `content/journey.ts`.
